# Selection Sort

Simple comparison-based sorting algorithm that repeatedly selects the minimum element and places it at the beginning.

## Complexity
- Time: O(n²) all cases
- Space: O(1) in-place
- Stable: No (but can be made stable)

## When to Use
- Small datasets
- Memory is extremely limited
- Number of swaps matters (only n-1 swaps!)
