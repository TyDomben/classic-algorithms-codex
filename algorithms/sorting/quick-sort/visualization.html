Algorithm Information

  • Time Complexity: O(n log n) average, O(n²) worst case
  • Space Complexity: O(log n) for recursion stack
  • Stable: No (can be made stable with modifications)
  • Method: Divide and conquer with in-place partitioning

How It Works

  1. Choose Pivot: Select the last element as pivot
  2. Partition: Rearrange array so elements < pivot are on left, elements > pivot are on right
  3. Place Pivot: Put pivot in its final sorted position
  4. Recurse: Apply same process to left and right subarrays
  5. Base Case: Subarrays of size 0 or 1 are already sorted
