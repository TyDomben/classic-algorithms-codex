How Bubble Sort Works

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they're in the wrong order. The largest element "bubbles" to the end with each pass.

  1. Compare adjacent elements
  2. Swap if in wrong order
  3. Repeat until sorted
