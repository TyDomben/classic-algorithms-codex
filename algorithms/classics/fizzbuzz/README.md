# FizzBuzz

> The classic programming interview problem

## Problem Statement

Print numbers from 1 to n, but:
- For multiples of 3, print "Fizz"
- For multiples of 5, print "Buzz"
- For multiples of both 3 and 5, print "FizzBuzz"
- Otherwise, print the number

## Example Output

```
1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz, 16...
```

## Why It's Famous

FizzBuzz became famous as a programming interview question that reportedly many candidates fail. It tests:
- Basic control flow
- Modulo operator understanding
- Conditional logic
- Attention to detail

## Complexity

- **Time:** O(n)
- **Space:** O(1)
